# Blade Proclamations

Blade Proclamations is a private, client-local Dalamud plugin for level 100 Samurai.

## Install through Dalamud

Add this URL under `/xlsettings` → **Experimental** → **Custom Plugin Repositories**:

```text
https://raw.githubusercontent.com/TheDiq/BladeProclamations/main/repo.json
```

Save, open `/xlplugins`, search for **Blade Proclamations**, and select **Install**.

It leaves every normal hotbar action untouched—including Iaijutsu, Tsubame-gaeshi, Ogi Namikiri, and their transformed actions. After the client processes one of your configured Samurai actions, the plugin:

- prints one private Echo-channel verse that only you can see;
- displays a movable, resizable, styled on-screen proclamation;
- animates blade-trail streaks, staggered opposing text slides, a slight anime-style overshoot, and a final fade/exit whoosh;
- distinguishes transformed actions by their actual action IDs;
- suppresses duplicate effect packets;
- never presses actions or sends party/server chat.

## Commands

- `/bladeproclaim` or `/bp` — open configuration
- `/bp test` — preview Ogi Namikiri
- `/bp unlock` — show and unlock the overlay for placement
- `/bp lock` — lock the overlay and make it click-through
- `/bp on` / `/bp off` — enable or disable the plugin

## Build requirements

- Windows x64
- Visual Studio 2022 with the **.NET desktop development** workload
- .NET 10 SDK
- XIVLauncher/Dalamud API 15

## Build

1. Open a terminal in this folder.
2. Run:

   ```powershell
   dotnet restore
   dotnet build -c Release
   ```

3. The dev DLL will be under:

   ```text
   bin\x64\Release\net10.0-windows\BladeProclamations.dll
   ```

4. A packaged `latest.zip` should also be generated by Dalamud.NET.Sdk under the Release output.

## Load as a development plugin

1. Launch FFXIV through XIVLauncher.
2. Enter `/xlsettings`.
3. Open **Experimental**.
4. Add the complete path to `BladeProclamations.dll` under **Dev Plugin Locations**.
5. Enter `/xlplugins`.
6. Open **Dev Tools → Installed Dev Plugins**.
7. Enable **Blade Proclamations**.
8. Enter `/bp unlock`, move/resize the panel, then enter `/bp lock`.

## First test

1. Enter `/bp test` and confirm the private Echo message and overlay appear.
2. Go to a striking dummy as Samurai.
3. Use Meikyo Shisui or another configured action.
4. Confirm that normal hotbar transformations still work and the verse appears only when the action resolves.

## Important

Third-party plugins are not permitted by Square Enix's FFXIV User Agreement. Use at your own risk, never discuss plugins in in-game chat, and disable the plugin if a game/Dalamud update makes it incompatible.

The action-effect listener is observation-only, but it is built against game structures that may change after patches. Dalamud generally disables incompatible plugins until they are updated.
